# Context

Use this folder for durable coaching context that should survive across Codex sessions: athlete preferences, recurring constraints, medical/recovery caveats, equipment decisions, and plan-change rationale. Put formal tracked goals in `plan/goals.md`; use this folder for narrative rationale around them.

Suggested files:

- `athlete.md`
- `season-goals.md`
- `constraints.md`
- `equipment.md`
